# Bai 3: Continuous Integration

Workflow `.github/workflows/ci.yml` trigger push/pull_request; `mvn clean verify` đi qua validate, compile, test, package, verify. Artifact lưu file JAR. Demo tạo test sai rồi sửa; chụp run đỏ và xanh.

Chi tiet: xem README.md, EVIDENCE/README.md va cac scenarios lien quan.
