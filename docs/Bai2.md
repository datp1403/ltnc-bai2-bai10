# Bai 2: Checkstyle, Refactor, Logging

Run `mvn checkstyle:check`. Google Java Style kiểm tra cách viết, tên và định dạng; refactor sửa code nhưng giữ nguyên chức năng. Logback tại src/main/resources/logback.xml theo dõi INFO/WARN/ERROR/DEBUG. Kết quả cần ảnh BUILD SUCCESS và log.

Chi tiet: xem README.md, EVIDENCE/README.md va cac scenarios lien quan.
